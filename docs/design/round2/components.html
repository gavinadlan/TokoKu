Lembar komponen, putaran 2

Semua kontrol memakai token yang sama dengan toko. Setiap komponen ditampilkan dalam state normal, hover, fokus, nonaktif, dan loading bila relevan.

Select dan dropdown kustom

Pilihan dibangun dengan primitif headless (Radix Select) agar daftar bisa diberi gaya dan tetap aksesibel (panah, Home/End, ketik huruf awal, Escape). Di perangkat sentuh dipakai select native karena pemilih bawaan ponsel lebih nyaman.
