Font untuk PDF invoice (dirender di backend, yang tidak membaca font variabel/WOFF2).

- Fraunces (c) 2020 The Fraunces Project Authors (https://github.com/undercasetype/Fraunces)
- Hanken Grotesk (c) 2021 The Hanken Grotesk Project Authors (https://github.com/marcologous/hanken-grotesk)

Keduanya dilisensikan di bawah SIL Open Font License 1.1 (OFL-Fraunces.txt, OFL-HankenGrotesk.txt).
Berkas .ttf di sini adalah INSTANS STATIS yang dibuat dari font variabel (subset latin, paket npm @fontsource-variable)
dengan fontTools (instancer): Fraunces wght 340/opsz 72, wght 560/opsz 48, italic wght 400/opsz 48; Hanken Grotesk wght 400 dan 600.
Kedua font tidak mendeklarasikan "Reserved Font Name" pada pernyataan hak ciptanya, sehingga versi yang dimodifikasi ini
boleh disertakan tanpa mengganti nama. Ketentuan OFL yang tetap berlaku: hak cipta dan lisensi ikut didistribusikan,
font tidak dijual terpisah, dan karya turunan tetap di bawah OFL.
